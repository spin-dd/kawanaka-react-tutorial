# kawanaka-react-tutorial

React の学習用リポジトリです。
小さなアプリ（月次締めつきの小遣い帳）を、ゼロから 1 つずつ機能を積み上げて作っていきます。

## 登場人物

| 役割 | やること |
| --- | --- |
| 学習者 | Issue を 1 つずつ実装し、PR を出す |
| 教育担当 | Issue を作る。PR をレビューする |

## 進め方

1. 教育担当が Issue を 1 つ作る。
2. 学習者は `main` から作業用ブランチを作り、Issue の内容を実装する。
3. 学習者は **1 つの Issue につき 1 つの PR** を作る。PR の説明欄には、Issue の「確認問題」への答えを自分の言葉で書く。
4. 教育担当がレビューする。指摘があれば学習者が修正し、問題なければマージする。
5. 次の Issue へ進む。

Issue は先にまとめて作らず、1 つ終わるごとに次を作ります。レビューの中で見えてきた課題を、次の Issue に反映するためです。

## 方針

- **実装の効率は重視しません。** 速く作ることより、「なぜそう書くのか」を自分の言葉で説明できることを優先します。
- **学習のチャンスがあれば、積極的に課題に組み込みます。** 本筋から少し外れていても、知っておいた方がよいことが出てきたら、Issue として追加します。
- 行き詰まったら 30 分を目安に、何を試して何が起きたかをまとめて教育担当に相談してください。自分で調べ続けるより、聞いた方が早いことは多いです。

## 目標成果物

最終的に作るアプリのサンプルを [`docs/goal/kozukai-sample.html`](./docs/goal/kozukai-sample.html) に置いています。
ブラウザで開くとそのまま動きます（CDN からライブラリを読み込むため、ネットワーク接続が必要です）。

主な機能は次のとおりです。

- 月ごとの明細一覧と、収入・支出・残高のサマリ
- 明細の追加・編集・削除（編集と削除は明細詳細ページから）
- 月次締め。締めた月の明細は変更できない。締めは月の順番どおりに行う
- 「今月を締める」ボタンは、条件がそろったときだけ表示される
- 締め済の月や今月より先の月には明細を登録できない。10,000 円以上の支出は備考が必須
- カテゴリ別の月予算と、超過したときの警告

> **NOTE**: このサンプルは「どんな画面を目指すか」を見るためのものです。
> 1 つの HTML ファイルに全部書いてあり、このリポジトリで作っていく構成とは違います。
> コードを写して実装するのではなく、画面と動きを確認する用途で使ってください。

## 開発サーバーの起動手順

1. リポジトリをクローンして、フォルダに移動する

   ```bash
   git clone https://github.com/spin-dd/kawanaka-react-tutorial.git
   cd kawanaka-react-tutorial
   ```

2. 依存パッケージをインストールする

   ```bash
   npm install
   ```

3. 開発サーバーを起動する

   ```bash
   npm run dev
   ```

4. ブラウザで http://localhost:5173/ を開く
