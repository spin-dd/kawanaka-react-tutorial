# kawanaka-react-tutorial

このリポジトリでは、React の学習用アプリを 1 つ、ゼロから積み上げて作っていきます。
その土台として、Vite + React + TypeScript のプロジェクトを作成しています。

## 開発サーバーの起動手順

1. リポジトリをクローンして、フォルダに移動する

```bash
   git clone https://github.com/spin-dd/kawanaka-react-tutorial.git
   cd kawanaka-react-tutorial
```

2. 依存パッケージをインストールする

```bash
   npm install
```

3. 開発サーバーを起動する

```bash
   npm run dev
```

4. ブラウザで http://localhost:5173/ を開く
